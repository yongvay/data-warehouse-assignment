--- EXHIBIT 2.3  Return rate by supplier, WITH the noise band ------------- PROMPT THE KEY EXHIBIT. expected_returns is what each supplier would see if
returns were distributed purely in proportion to units sold.
z_score measures how far the actual result sits from that expectation
in standard deviations. Roughly: |z| under 2 is indistinguishable from
chance. If every supplier lands inside that band, there is no quality
outlier and the honest finding is that no supplier warrants action.
