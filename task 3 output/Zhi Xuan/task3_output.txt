REPORT 2 - PEAK TRADING HOURS AND WEEKDAY/WEEKEND PATTERN BY REGION
Facts / Dims : sales_fact (order_hour) x date_dim (weekday_ind,
day_week) x branch_dim (branch_region)
Measures     : net sales by hour block, peak block, weekday and
weekend sales, weekend share, rank

THE QUESTION: staff rosters and delivery slots are set regionally,
not nationally. Four of the five regions turn out to peak in the
same After-work block, so the block mix alone does not justify a
regional roster - Exhibit 2.3 is where the regions actually differ.

NOTE: this report measures the SHAPE of the trading day, not growth,
so the part year 2026 is included without distortion. Hour blocks

BLOCK BOUNDARIES ARE SET FROM THE DATA, NOT FROM CONVENTION. The
warehouse holds no orders before 08:00 and effectively none after
22:00 - one order at 23:00 in the whole era - so the branches trade
08:00-22:00. A conventional Morning/Afternoon/Evening/Night split
would leave the Night column empty, and it would put 17:00 on a
block boundary. 17:00 is the busiest single hour in the Southern
region, so that boundary alone would decide whether Southern is
classed Afternoon or Evening. The blocks below follow the shape of
the trading day instead: Opening 08-11, Midday 12-16, After-work
17-19, Late 20-22.

REPORT 3 - BRANCH RETURN LEAKAGE: REFUND-TO-SALES BY CAUSE
Facts / Dims : sales_fact + return_fact x branch_dim x
return_reason_dim x date_dim
Measures     : net sales, refund amount, refund-to-sales percent,
Fulfilment vs Product Quality split, days to return

THE QUESTION: a refund is revenue that was booked and then handed
back. The percentage matters more than the absolute, because the
largest branch will always refund the most ringgit. The cause split
is what makes the number actionable: Fulfilment-caused returns
(Missing, Wrong Item) are a branch picking and packing failure and
the branch manager owns them. Quality-caused returns (Broken,
Expired) are a supplier, handling or cold-chain failure and
procurement owns them. Same symptom, different department.

COUNTED AS LEAKAGE: return_status IN ('Approved','Refunded') only.
A Pending or Rejected return has not cost the company anything yet.
============================================================================

rank is built on it, not on refund ringgit, so a large branch is not
punished for being large. The two cause columns are the same refund
value split by who owns the fix. Avg Days to Return is a diagnostic:
a Quality problem found in two days is damage in transit, one found in
twenty is shelf life. The subtotal rows below each region come from
BREAK ON with COMPUTE SUM.

HOW THE TWO FACTS ARE COMBINED: each fact is collapsed to one row per
branch in its own CTE before the join. A direct join of the two line
grain tables would multiply every sales line by every return line.
